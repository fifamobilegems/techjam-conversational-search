# Build-time dependencies for the `sentence-transformer` encoder backend.
#
# Only needed to RUN `python -m scripts.build_embeddings` with the default
# backend, and to encode queries against the artifact it produces. Pulls in
# torch (~2 GB). The `hashing` backend needs none of it:
#
#     EMBEDDING_BACKEND=hashing python -m scripts.build_embeddings
#
# The model is downloaded once and cached; encoding afterwards is fully
# offline, which matters because organizer policy may disable network access
# during official scoring (docs/submission_rules.md).
